## 동작

- 개인별 또는 팀별 최종 조건을 서버에서 평가합니다. 전체 콘텐츠 완료가 기본이며 제작 설정에서 최종 콘텐츠를 지정할 수 있습니다. 지정한 블록의 기존 공개·배정·협동 완료 조건을 유지합니다.
- 최초 도착 시각, 유효 소요 시간, 제외된 정지 시간, 오답·힌트·점수를 서버에 고정합니다. 새로고침·조회·중복 요청은 도착 시간을 변경하지 않습니다. 완료 후 새 제출·힌트·콘텐츠 선택은 차단합니다.
- 교사가 명시적으로 이동·잠금 해제·진행 초기화·팀 변경하면 해당 현재 결과를 무효화하고 조건을 재평가합니다. 보관된 결과는 바뀌지 않습니다.
- 팀 완료는 활성 팀원 모두에게 최종 조건이 충족되어야 합니다. 완료 판정 자체는 기존 any/all/N/배정/역할 규칙을 사용합니다. 미접속 학생을 자동 제외하지 않으며 교사가 미완료 수업을 종료할 수 있습니다.
- 힌트는 서버 요청으로 한 단계씩 공개합니다. 개인/팀/스테이지/방/무제한 사용량 설정을 검사합니다. 팀 공유 모드에서는 같은 힌트를 한 번 사용하고 팀원 모두에게 표시합니다.
- 문제 점수는 완료된 문제당 한 번 합산하며 팀원 수만큼 중복 가산하지 않습니다. 교사 강제 완료·건너뛰기도 기존 완료 조건과 같은 점수 기준을 적용하며 교사 감사 기록에 구분됩니다. 점수 페널티를 뺀 최저 점수는 0점입니다.
- 시간 순위는 유효 소요 시간, 오답·힌트·종합 모드는 설정된 시간 페널티를 더합니다. 점수 순위는 점수 내림차순입니다. 동률은 유효 시간, 도착 시각, 서버 대상 ID 순서로 고정합니다.
- 공개 설정은 실시간/수업 종료 후/교사 전용입니다. 학생 공개 순위에는 이름·순위·시간·허용된 점수만 포함하며 타 팀 문제·정답·세부 진행·복구 토큰은 포함하지 않습니다.
- 수업 종료는 완료하지 않은 참가자의 도착 기록을 만들지 않습니다. 미완료 대상은 기록에서 구분합니다.
- 초기화는 하나의 서버 트랜잭션으로 현재 세션 및 종속 상태를 삭제하고 새 대기실 세션을 만듭니다. 콘텐츠·고정 코드는 유지되고 학생은 다시 입장합니다. 새 세션은 최신 콘텐츠 설정을 사용합니다.
- 보관 선택 시 이전 세션의 결과 스냅샷을 별도 저장합니다. 삭제 선택은 현재 수업 결과에만 적용되며 이전에 보관한 수업은 유지합니다. 콘텐츠 자체를 삭제하면 그 콘텐츠의 보관 결과도 함께 삭제됩니다.
- 초기화 요청 중복 방지용 최소 영수증은 콘텐츠에 연결해 유지합니다. 학생 이름·정답·진행 데이터는 들어가지 않습니다.

## 테이블·권한

신규: `escape_results`, `escape_hint_uses`, `escape_result_archives`, `escape_reset_receipts`.

모든 신규 테이블은 RLS 활성화 및 anon/authenticated 직접 접근 철회 상태입니다. 학생은 복구 토큰을 검증하는 기존 RPC로 제한된 결과만 받습니다. `escape_finish_reset`, `escape_result_history`는 인증된 소유 교사만 사용할 수 있습니다. private 함수 호출은 클라이언트 역할에 허용하지 않습니다. 실제 오답 문자열을 저장하지 않으며 Secret/service_role 키를 추가하지 않았습니다.
